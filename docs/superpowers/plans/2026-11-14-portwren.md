# Port Wren Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new XTApp, Port Wren 1.0.0: generated, provably solvable murder cases in a 1920s harbour town, with a career (a town with a memory, and rank) or single cases.

**Architecture:**
- **`src/main.lua`:** the screens, input, saving and Back. It is bundled with gamekit into `index.lua`, like Delve.
- **Package files under `game/`:** the game logic, loaded with `_G.require`, like apps/calculator/modes.
  - `town` and `text` load on start.
  - `gen` and `solver` load only when a case is made.
- **Making a case:** the generator builds the truth, derives clues and lies, and the solver accepts or
  rejects the case. Generation runs in a coroutine, resumed from `ctx:after` slices.

**Tech Stack:**
- Lua (the device runs 5.5, the tests run 5.4 through lupa);
- the gamekit harness (`tools/gamekit/harness.py`);
- Python 3 for the tests and an independent brute-force checker.

**Spec:** `docs/superpowers/specs/2026-11-14-portwren-design.md`

## Global Constraints

- **No commits until the device test passes** (the user's rule). Tasks end with a green test run, not a commit. Task 10 commits everything at once, after the device test.
- **Spec and plan stay uncommitted** until then too. Don't commit `docs/ideas/`.
- **Package `apps/portwren/`:**
  - manifest `app_id` "portwren", `display_name` "Port Wren", `version` "1.0.0" (always three numbers), `entry` "index.lua", `permissions` [];
  - `api`: the lowest version that covers what is used ("2.0" unless something newer is needed).
- **Screen:** 480x800, portrait only, 1-bit.
- **Frames:** one redraw per tap that changes something. At most about 900 draw commands per frame, which tests check.
- **Time limits:** an input callback must finish under 1000 ms and `on_draw` under 1500 ms. Heavy work goes through `ctx.budget:extend()` and `ctx:after` slices.
- **Back:** act on the `up` phase (or no phase); inner screens go back a level; the outermost screen returns `false` on up. Pattern: `apps/checkers/src/main.lua` `on_input`. Tests send down, then up.
- **Text and tone:** English. Deaths are reported, never described (no gore). All names, the town and the characters are original.
- **Saves:** written on every tap that changes state, to `town.txt` and `case.txt` through `kit.write`.
- **Lint:** every `.lua` passes `python -I tools/lualint55.py` (no assignment to a for-loop variable).
- **Never trust a clue path that low trust can block.** Trust may add 1 action, never remove a clue.

## Shared data model (every task uses these names)

**Constants** (in `game/text.lua` as `T.PLACES`, `T.JOBS`, `T.MOTIVES`, `T.MEANS`):
- **Means:** `'poison'`, `'blunt'`, `'knife'`, `'drowning'`.
- **Motives:** `'debt'`, `'inheritance'`, `'jealousy'`, `'blackmail'`, `'revenge'`, `'secret'`. The second crime's motive is `'silencing'`, which the accusation never asks about.
- **Patterns:** `'classic'`, `'alibi'`, `'timeline'`, `'liar'`.
- **Sizes:**
  - `'short'`: 4 suspects, 5 places, 8-12 clues, 24 actions (2 days).
  - `'long'`: 6 suspects, 7 places, 13-19 clues, 2 false trails, 36 actions (3 days).
- **Time:**
  - Evening slots 1..12 are 18:00 + 30 min x (s-1).
  - Night-2 slots 13..18 are 21:00 + 30 min x (s-13).
  - Parts of a day are 1..4 (morning, afternoon, evening, night), with 3 actions each.

**The place pool:** `T.PLACES[key] = {name=, jobs={job keys}, means={means keys found there}}`, 16 entries.
Keys: `inn`, `harbour_office`, `pier`, `fish_market`, `warehouse`, `chapel`, `doctor`, `lighthouse`, `boarding`,
`bank`, `chemist`, `boatyard`, `customs`, `bakery`, `school`, `cottages`.

**Person:**
```
{id=int, name=str, sex='f'|'m', job=key, work=place key, home=place key, traits={key,key},
 trust=0..100, status='alive'|'dead'|'jailed'|'gone', hist={{case=int, what='accused'|'arrested'|'helped'|'widowed'|'bereaved'}}}
```

**Town:**
```
{v=1, seed=int, mode='career'|'single', people={[id]=person}, rel={{a=id, b=id, k='spouse'|'sibling'|'employer'|'debtor'|'rival'|'lover'|'grudge'}},
 places={10 keys}, rep=int, rank=1..4, solved=int, partial=int, lost=int, case_no=int, next_id=int}
```

**Fact:**
- `{t='at', who=, place=, slot=}`;
- `{t='access', who=, means=, yes=bool}`;
- `{t='motive', who=, motive=}`;
- `{t='window', lo=, hi=}`;
- `{t='secret', who=, slot=, place=}`.

**Clue:**
```
{id=int, kind='physical'|'document'|'testimony'|'observation', src='cert'|witness id, facts={fact...},
 gate={k='search', place=} | {k='talk', who=} | {k='ask', who=, topic=} | {k='show', who=, clue=id},
 need=bool, trail=bool, tpl=str, vars={...}}
```
`src='cert'` for physical, document and observation clues. A testimony's `src` is the witness's id.

**Case:**
```
{v=1, seed=, no=, pattern=, size=, victim=, killer=, suspects={ids incl. killer}, witnesses={ids}, motive=, means=,
 scene=, slot=, window={lo=,hi=}, moves={[pid]={[slot]=place}}, sched={[pid]={[part]=place}},
 access={[pid]={[means]=true}}, motives={[pid]=motive}, says={[pid]={[slot]=place}}, secret=nil|{who=,slot=,place=,what=},
 clues={clue...}, night2=nil|{victim=,scene=,slot=}, strikes=0, found={[id]=true}, talked={[pid]=int},
 clock={day=1,part=1,used=0}, days=2|3, board={{clue=,who=}}, over=nil|'solved'|'partial'|'lost', guess=nil|{who=,motive=,means=}}
```
- `says` holds the statements: equal to `moves` except for lies.
- `moves` and `says` include night-2 slots once `night2` exists.

**The reasoning rules** are the spec's section "The solver", verbatim. The Lua solver (Task 4) and the Python checker (Task 4) implement them separately.

### Task 3: The truth model and the clues (Classic)

**Files:**
- Create: `apps/portwren/game/gen.lua`
- Test: `apps/portwren/test_cases.py` (grows in Tasks 4-6)

**Interfaces:**
- Consumes: `W`, `T`, `R` (Tasks 1-2).
- Produces:
  - `game/gen.lua` returns `function(T, R, W) -> G`.
  - `G.build(town, opts) -> case`, where `opts = {seed=, size=, pattern=, no=}`. One attempt, no solver check. It fills every Case field except `found`, `talked` and `board`. `clock = {day=1, part=1, used=0}`, and `days` is 2 or 3.
  - `G.reachable(case, town) -> {[clue_id]=true}`, `G.cost(case, town) -> int`, and `G.TOTAL = {short=24, long=36}`.
- **How to build (Classic):**
  - **The cast:** pick the victim, then a killer with a relationship that gives a motive (debtor → debt, spouse or lover → jealousy or inheritance, grudge → revenge, any → blackmail or secret). Pick the means from the killer's work place or home `means`, and the scene among the case's places.
  - **The crime slot:** the slot is in 3..10, and `window = {lo=slot, hi=slot}`.
  - **The innocents** (the other suspects) each get a reason to look guilty: a motive fact, access to the means, or being near the scene.
  - **Moves:** every suspect's moves cover slots 1-12, moving at most one place per slot. The killer is at the scene at the slot.
  - **`says`:** a copy of `moves`. The killer lies at the slot, claiming a place they were not.
  - **Classic clues:**
    - access clues: at least one per suspect, for or against;
    - motive documents for the killer and at least one innocent;
    - believed `at` facts that clear all innocents but one;
    - one `cert` fact that contradicts the killer's claim at the slot: physical or observation, for example wet hands, a torn ticket, mud from the scene.
  - **Gates:** a clue is gated at a place among the case's places, or at a person among suspects or witnesses. A `show` gate needs a clue with a lower id, so the gates form a graph with no cycles.
  - **The cost:** `G.cost` is the actions needed to reach every `need=true` clue. Each distinct place searched counts 1, each distinct person talked to counts 1, and +1 per person with trust < 30.
- **`<test>`:** in `test_cases.py`, a helper `build(seed, size, pattern)` loads `game.gen` through `package.path` and returns the case as a Python dict (convert through `S.encode` and a Python parser, or walk the lupa table). It checks that, for seeds 1..200 in both sizes:
  - the suspect count is 4 or 6, and the victim is not a suspect;
  - `moves[killer][slot] == scene` and `says[killer][slot] != scene`;
  - every innocent's `says == moves`;
  - every gate's place is in the town's places, and every gate's person is alive;
  - the show gates have no cycle;
  - the clue count is in range for the size.

### Task 4: The solver, the acceptance loop and the independent checker

**Files:**
- Create: `apps/portwren/game/solver.lua`
- Modify: `apps/portwren/game/gen.lua` (add `G.new_case`)
- Test: `apps/portwren/test_cases.py`

**Interfaces:**
- Consumes: `G.build`, `G.reachable`, `G.cost` (Task 3).
- Produces:
  - `game/solver.lua` returns `V`:
    - `V.solve(case, known) -> res`, where `known = {[clue_id]=true}` and `res = {slots={...}, cleared={[pid]=true}, liars={[pid]=true}, guilty={ids}, motive={[pid]=motive}, means_known=bool}`.
    - The rules come from the spec's "The solver".
    - `slots` is the possible crime slots after `window` facts and time facts. Opportunity and contradiction apply to the remaining slot; while more than one is left, nobody is cleared by opportunity.
    - `V.check(case, town) -> true | false, reason`. A case is accepted when:
      - (a) with all reachable clues, `#guilty == 1`, it is the killer, the killer's motive is known and the means is known;
      - (b) the pattern shape holds. For Classic: with every clue known except the contradiction clues (those whose facts contradict the killer's `says`), exactly 2 suspects are not cleared and the killer is one of them;
      - (c) `G.cost(case, town) <= 0.6 * G.TOTAL[size]`;
      - (d) every `need` clue is reachable.
  - `G.new_case(town, opts) -> case`. Run it inside a coroutine; it calls `coroutine.yield()` after every attempt when `coroutine.isyieldable()`.
    - It tries `G.build` and `V.check` with child seeds `R.mix(opts.seed, k)` for k = 1..50.
    - After 50 failures, it tries Classic with k = 51..150, which must succeed. If even that fails, it raises an error, which the test proves never happens.
    - `case.pattern` records the pattern actually used.
- **The independent checker:** `test_cases.py` gets a pure-Python `brute(case)`.
  - It enumerates every (suspect, motive, means), and keeps a triple when it fits the rules applied to all reachable facts: the suspect is not cleared, has access to the means, has that motive, and their crime-slot claim is contradicted or they are placed at the scene.
  - It is written without reading `solver.lua`.
- [ ] **Step 1: Write the failing tests.** For seeds 1..1000, short and long, Classic:
  - `new_case` returns a case;
  - `brute(case)` gives exactly one triple, equal to `(killer, motive, means)`;
  - the Lua `V.solve` agrees;
  - the cost is at most 14 (short) or 21 (long);
  - with every person's trust set to 0 before generating, the case is still accepted and still within the time budget (trust adds cost, never removes a clue).
  - A time test: with a fake clock stub (the `tick_clock` idea of `apps/checkers/test_checkers.py:116-127`), one attempt costs under 150 ms of the harness's Lua time on average. Measure with `time.perf_counter` around 100 builds and print it.
- [ ] **Step 2: Run** `python -I apps/portwren/test_cases.py`.
  - Expected: it fails, with the solver missing.
- [ ] **Step 3: Implement** `solver.lua` and `G.new_case`. Change `G.build`'s clue choice until the 1000-seed run passes; don't loosen the checks.

### Task 5: The other patterns and false trails

**Files:**
- Modify: `apps/portwren/game/gen.lua`, `apps/portwren/game/solver.lua` (the shape checks)
- Test: `apps/portwren/test_cases.py`

**Interfaces:**
- Consumes: Tasks 3-4.
- Produces: `G.build` handles `pattern = 'alibi' | 'timeline' | 'liar'`, and `trail=true` clues in Long cases. `V.check`'s shape checks per pattern:
  - **alibi:**
    - one witness `w` gives a testimony placing the killer elsewhere at the slot (`says[w]` is consistent with it);
    - with that testimony believed and the catching `cert` fact unknown, the killer is cleared;
    - with all clues known, `w` is a liar and the killer is the only one guilty.
  - **timeline:**
    - `window` spans 3-4 slots, with the true slot inside;
    - time clues (facts of the form `{t='window'}` narrowing it, such as a stopped clock or the ferry) leave exactly one slot only when all are known;
    - with every time clue unknown, at least 2 suspects stay not cleared.
  - **liar** (Long only):
    - an innocent `i` lies at the crime slot (`says[i][slot] ~= moves[i][slot]`);
    - a `{t='secret'}` clue, reachable and `need=true`, places `i` elsewhere at the slot, so `i` is cleared;
    - without the secret clue, `i` is a liar and not cleared.
  - **false trails:** each Long case has exactly 2 clues with `trail=true`. They are true facts (a motive, being near the scene, or access) about innocents, never about the killer, and never needed.
- [ ] **Step 1: Write the failing tests.** For seeds 1..1000:

  - Long cases have exactly 2 trail clues, all about innocents;
  - `G.new_case` with `pattern='liar'` and `size='short'` raises an error (a caller bug);
  - the fallback: when `G.build` is forced to fail for non-Classic patterns (by a test stub that makes `V.check` reject them), `new_case` returns a Classic case.

### Task 7: The text

**Files:**
- Modify: `apps/portwren/game/text.lua`
- Test: `apps/portwren/test_text.py`

**Interfaces:**
- Consumes: the Case and Town models.
- Produces, all pure functions of `(case, town, ...)` and an `r` (rng) for picking variants:
  - `T.clue(case, town, clue, r) -> str`, from `clue.tpl`, `clue.vars` and its facts.
  - `T.statement(case, town, pid, night) -> {lines}`: their account, slot runs merged ("From six until half past seven I was at the Anchor inn.").
  - `T.greet(case, town, pid, r) -> str`: in the trait voice (nervous hedges, proud bristles), with a line from `hist` if any ("You arrested my brother in case 3.").
  - `T.answer(case, town, pid, topic, r) -> str`, and `T.topics(case, town, pid) -> {keys}`. Topics are `victim`, `evening`, people's names, and places.
  - `T.react(case, town, pid, clue, r) -> str`, the reply when shown a clue.
  - `T.account(case, town) -> {lines}`, the end-of-case solution: who, why, how and when, and the clue ids that proved it.
