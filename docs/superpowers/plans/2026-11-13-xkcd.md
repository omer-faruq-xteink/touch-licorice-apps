# xkcd 1.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new app that reads xkcd: latest / Prev / Next / Random / #, wide comics in landscape, tap-to-zoom with drag, alt text, favourites, the last 20 comics offline, and the latest comic on the sleep screen.

**Architecture:** gamekit app (`apps/xkcd/`): pure helpers in `src/xk.lua` (URLs, JSON to comic, PNG size, fitting, cache and favourites lines), the app in `src/main.lua`, the sleep screen in `src/lock/lock.lua` bundled with gamekit and xk.lua into `lockscreen.lua` by `bundle.py` (the Hacker News pattern).

**Tech Stack:** Lua (XTOS Licorice API 2.26), tools/gamekit, Python + lupa tests.

**Spec:** docs/superpowers/specs/2026-11-13-xkcd-design.md

## Global Constraints
- JSON: `https://xkcd.com/info.0.json` (latest), `https://xkcd.com/<n>/info.0.json`; no comic 404.
- Image: one request with `save = { to = "storage", name = ... }` (≤ 262144 B); decode with `ctx.image:decode(bytes, { max_w, max_h })` (≤ 1024 px a side). Over 1024 px or 256 KB (or the save failing): `https://images.weserv.nl/?url=<enc img>&w=1024&h=1024&fit=inside&output=jpg&q=70&filt=greyscale`, shown with "(reduced)".
- Landscape when the comic is wider than tall (`ctx.screen:set_orientation`), else portrait; layout from `ctx.screen.width/height`.
- Cache: last 20 comics (`cache.txt` + `c_<n>.png|jpg`); favourites `favourites.txt` "n<TAB>title"; settings `settings.txt` (`last=`, `lockevery=` hours 3/6/12, default 6).
- Sleep screen: lockscreen {enabled, entry lockscreen.lua, interval_sec 3600, net true}; own files `lock.txt`, `lock.png|jpg`; Weather's lock rules (set_interval 3600 each session, 120 s slack, early wake held with ctx:after, done when nothing pending).
- Credit "xkcd by Randall Munroe · xkcd.com · CC BY-NC 2.5" in Settings and the README.
- Manifest: app_id `xkcd`, "xkcd", 1.0.0, api 2.26, permissions net, requires pointer.
- Tests: `python -I apps/xkcd/test_xk.py`, `test_xkcd.py`, `test_lock.py`; lint `python tools/lualint55.py`. No commits before the device test.

## Review Focus
1. A truncated or corrupt image body (save failed, decode error): the app falls back to weserv once, then shows the title, alt and a QR code; never a crash or an endless "loading".
2. Navigation edges: Next on the latest, Prev on 1, # with 0, 404, a number past the latest or text: a message, no request.
3. Turning: going from a landscape comic to a portrait one turns back; Back from a landscape comic to Settings/Favourites lays them out for the screen as it is.
4. Offline start with an empty cache: a clear "needs Wi-Fi" screen, the buttons still work once Wi-Fi is back (Reload).
5. Alt text longer than the space under a portrait comic: wrapped and cut with "…", the full text in the Alt box.
