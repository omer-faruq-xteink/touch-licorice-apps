# Suguru (Tectonic) — XTOS Licorice mini app

The grid is split into regions of one to five cells (thick borders). A region of n cells holds
the numbers 1 to n, each once, and touching cells, diagonals included, never hold the same number.

## Playing

- Tap a cell, then a number on the pad (1-5). **Erase** clears the cell.
- **Chk** (on by default) crosses the cells that break a rule right now: a number too big for its
  region, a repeat in a region, or the same number in touching cells.
- **Next** moves to the next puzzle, **Bank** to the next bank; the side buttons step back and
  forth through the bank. Your place and the grid are kept between runs.
- Numbers you entered are underlined; givens are not and cannot be changed.

Lines and digits are drawn heavier than in Sudoku (3 px region borders, digits drawn twice) so
the grid stays readable on panels that show thin lines faintly.

## Banks

| bank | size | puzzles |
|---|---|---|
| `5x5-easy` | 5 x 5 | 200 |
| `6x6-medium` | 6 x 6 | 200 |
| `7x7-hard` | 7 x 7 | 200 |
| `8x8-expert` | 8 x 8 | 200 |

The puzzles are generated by `make_bank.py` (our own code, no third-party puzzles), the way
published Suguru are made: **one solution, reached by logic, no guessing**. Regions are grown at
random, a random solution is found, then givens are removed as long as a solver that only uses
human techniques can still finish:

| level | techniques |
|---|---|
| basic | a placed number leaves its region and the touching cells; a cell with one candidate left |
| 1 | hidden single: a number with one place left in its region |
| 2 | naked / hidden pairs and triples in a region |
| 3 | forbidden neighbour: every place left for a number in a region touches one outside cell, so that cell cannot hold it |

The easy bank needs level 1 at most; medium, hard and expert use all levels and are never solved by
the basic steps alone. Puzzles are scored the way pzl.org.uk scores its Suguru (points per
technique per cell); hard and expert keep the higher-scoring half of what was generated, and each
bank runs from its easiest puzzle to its hardest. A few puzzles are also built into `index.lua` in
case the data section cannot be read.

```bash
python apps/suguru/make_bank.py --count 200
```

## Files

- `index.lua` — the app (Lua API 0.8, like Sudoku).
- `data/*.txt` — the banks: one puzzle per line, n*n region letters then n*n digits (0 = empty).
- `make_bank.py` — the generator and solver.
- `test_suguru.py` — offline test: `python -I apps/suguru/test_suguru.py`.
