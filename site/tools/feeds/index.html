Feed lists

The RSS app reads feeds on the reader itself, with no account. Add them on the reader (Add feed → Choose from a list shows the feeds below; Type an address takes a site, a feed or an OPML address), or copy an OPML file into AppFiles/rss/ on the SD card (USB mode): each file becomes a collection in the app's menu, next to My feeds.

Ready lists

One OPML file per topic. Download one and copy it to the reader, or type its address in Add feed → Type an address.

A list of your own

  1. Tick the feeds you want, and add others by their feed address (one per line).

  2. Name the collection and download it. The file name is the name the app shows.

  3. Copy it into AppFiles/rss/ and open RSS.

Good to know

  • An OPML exported from another feed reader (Feedly, Inoreader, NetNewsWire, CommaFeed...) works the same way.
  • The reader takes at most 128 KB per download. The feeds above fit; a larger feed shows its newest articles as far as they fit.
  • Many feeds carry only a summary of each article. A Worker of your own with a full-text service brings the whole text, and also takes feeds of any size.
