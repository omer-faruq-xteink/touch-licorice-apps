Tools for the reader's mini apps

Converters and setup helpers for the touch-licorice-apps mini apps on the Xteink X4 Pro. They run in this browser: nothing you add here is uploaded.

Getting files onto the reader

Each app has its own folder on the SD card, AppFiles/<app>/, for example AppFiles/gamebook/. Connect the reader by USB (USB mode), copy the files there, and open the app. Each app's help screen shows its folder (Anki and Dictionary copies installed by hand from a .xtapp file also read XTApps/<app>/files/).
